# Runnable

There are examples installed when `msl-qt` is installed.

They are found in the `../site-packages/msl/examples/qt` directory and also in the [repository].

You can select an example to run by running the following command in a terminal.

```console
python -c "from msl.examples.qt import run; run()"
```

[repository]: https://github.com/MSLNZ/msl-qt/tree/main/src/msl/examples/qt
